# Meds Widget

Meds Widget is a no-cost, native Android medicine-tracking utility built with
Kotlin, Jetpack Compose, Jetpack Glance, Firebase Authentication, and Cloud
Firestore.

V1 targets Android home-screen widgets, including Samsung One UI launchers.
It is a tracking utility only and does not provide medical, dosing, or
treatment advice.

- Android application ID: `io.github.ffelixq.medswidget`
- Repository: `ffelixq/meds-widget`
- License: no open-source licence has been assigned

Full setup, architecture, security, test, Firebase, CI/CD, and Samsung
validation documentation will be added on the V1 feature branch.
